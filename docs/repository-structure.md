# Repository Structure

```text
.github/                 GitHub templates and workflow checks
.vscode/                 VS Code settings
archive/                 Reserved for old exports
data/workbooks/          Excel timing and scaling workbooks
docs/                    Documentation and scientific notes
figures/drawio/          Editable diagram sources
figures/previews/        Preview images
manuscript/draft/        Draft manuscript document
manuscript/final/        Clean/final manuscript document
results/figures/         Validated regenerated figures
results/tables/          Validated exported tables
scripts/matlab/          MATLAB analytical model and wrappers
scripts/python/          Optional future helpers
tests/matlab/            Static MATLAB checks
```
