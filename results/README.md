# Results

This folder contains the curated result images and short discussions for the MMC computing scaling-law study.

## Final image set

Only one final result image is stored per analytical figure. The result set is intentionally limited to F1–F5 to avoid duplication.

| Figure | Image | Short discussion |
|---|---|---|
| F1 | `figures/F1_comm_vs_N.svg` | `discussion/F1_comm_vs_N_discussion.md` |
| F2 | `figures/F2_scaling_laws.svg` | `discussion/F2_scaling_laws_discussion.md` |
| F3 | `figures/F3_utilization.svg` | `discussion/F3_utilization_discussion.md` |
| F4 | `figures/F4_feasibility_heatmap.svg` | `discussion/F4_feasibility_heatmap_discussion.md` |
| F5 | `figures/F5_gantt.svg` | `discussion/F5_gantt_discussion.md` |

## Deduplication rule

The uploaded MATLAB `.fig` files contained six files but only five unique results. `2.fig` and `6.fig` both correspond to `F3 U(N)`, so only one `F3_utilization` result is kept in this folder.

## Reproducibility

The SVG images summarize the results generated by:

```text
scripts/matlab/mmc_scaling_analysis.m
```

To regenerate the MATLAB figures locally:

```matlab
run('scripts/matlab/run_all_scaling_figures.m')
```
