# Project Status

## Current state

This repository packages a scientific study on computational, communication, and scheduling limits of MMC control architectures. The material is organized for GitHub review, reproducibility, and future thesis/paper integration.

## Included in the prepared local ZIP

- MATLAB scaling-law generator.
- Manuscript draft and final document copies.
- Excel workbooks containing timing, scheduling, U(N), LUT, and figure data.
- DrawIO diagrams and PNG previews for Gantt-style figures.
- Documentation describing methodology, assumptions, limitations, and validation steps.

## Uploaded through ChatGPT GitHub connector

The repository was created and initialized on GitHub. Text-based source, documentation, and configuration files are uploaded directly where possible.

## Important connector limitation

Large binary artifacts such as `.docx`, `.xlsx`, and `.png` are included in the downloadable ZIP prepared in this chat, but may require local Git push if they do not appear on GitHub. The current connector path is reliable for UTF-8 text files.
